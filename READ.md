# DreamMakeup: Face Makeup Customization using Latent Diffusion Models

This is an unofficial implementation of the paper **DreamMakeup** (arXiv:2510.10918).

## Features
* **Early-stopped DDIM Inversion**: Preserves facial identity effectively.
* **Pixel-space Customization**: RGB color transfer with gradation smoothing.
* **Interpolation-guided Sampling**: Harmonizes makeup style while retaining skin details.
